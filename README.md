## 图片规格建议

- **格式**: PNG（支持透明背景）
- **尺寸**: 400x400px 或 1:1 比例
- **风格**: 建议统一风格，可用 AI 生成（Midjourney/Stable Diffusion）
- **背景**: 透明或与网站深色主题协调

## 备用方案

如果不想添加图片，网站会优雅降级，在结果页显示文字描述。
